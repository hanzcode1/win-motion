Quick Start

  1. Buka halaman Compositions → klik Composition Baru
  2. Pilih template, beri nama, klik Simpan
  3. Buka halaman Studio → pilih composition → atur preset
  4. Klik Render Video → tunggu proses
  5. Lihat hasil di halaman Renders

API Remotion-like

useCurrentFrame()

Nomor frame saat ini (mulai dari 0).

const frame = useCurrentFrame();

useVideoConfig()

Info video: fps, width, height, duration.

const { fps, width, height } = useVideoConfig();

interpolate()

Map frame ke range nilai.

interpolate(frame, [0, 30], [0, 100], { extrapolateRight: 'clamp' })

spring()

Animasi pegas fisika.

spring({ frame, fps, config: { damping: 12 } })

Contoh Composition

declare const React: any;
declare const Remotion: any;

const { useCurrentFrame, useVideoConfig, interpolate, AbsoluteFill } = Remotion;

export default function MyComp() {
  const frame = useCurrentFrame();
  const { durationInFrames } = useVideoConfig();

  const opacity = interpolate(frame, [0, 20], [0, 1]);

  return React.createElement(
    AbsoluteFill,
    { style: { background: '#0078d4', opacity } },
    React.createElement('h1', { style: { color: 'white' } }, 'Hello!')
  );
}

Error Umum

❌ ffmpeg gagal

Pastikan ffmpeg-static terinstall. Cek dengan npm run doctor.

❌ Chrome tidak ditemukan

Install Google Chrome, atau set env CHROME_PATH.

❌ Render sangat lambat

Kurangi resolusi (720p), atau pakai quality Low.
